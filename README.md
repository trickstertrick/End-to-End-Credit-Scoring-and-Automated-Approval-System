# End-to-End-Credit-Scoring-and-Automated-Approval-System
PostgreSQL, FastAPI ve Streamlit ile geliştirilmiş uçtan uca kredi skorlama sistemi. Müşteri verilerini veri tabanında saklar; K-Means ile risk segmentasyonu, Lojistik Regresyon ile dinamik onay/red olasılığı hesaplar. Sonuçları görsel bir dashboard üzerinde gerçek zamanlı raporlar.
